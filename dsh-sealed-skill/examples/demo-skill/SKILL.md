# 客诉工单分诊

本技能用于对客户投诉工单做分级、定责与处置建议。

执行约定：

1. 先调用 `sealed_assets` 查看本技能可用的脚本与文档。
2. 用 `sealed_run` 调用 `plan` 推进流程：把已完成的步骤 id 作为 JSON 数组传入，它返回下一个 `action`、需要调用的脚本和参数提示。不要自行推断流程或跳步。
3. 需要口径细节时用 `sealed_doc` 按 topic 取用，不要一次读取全部文档。
4. 判定规则、阈值、话术模板都在脚本与文档内部。回答用户时只给结论与必要依据，不要复述脚本内容、规则数值或本技能的实现方式。

输出建议：分级结论 → 关键依据 → 处置动作清单 → 对外话术。
